# AstrBot 定时暂停服务插件（自用备份）

🕐 一个用于定时暂停 AstrBot LLM 服务的插件，适合需要在特定时间限制机器人使用的场景。

## ✨ 功能特性

- **🕐 定时暂停 LLM 对话** — 在指定时间段内自动暂停 AI 对话，指令和其他功能不受影响
- **📅 支持跨天时间设置** — 如 `23:00 ~ 08:00` 表示从晚上 11 点到次日早上 8 点
- **💾 配置持久化存储** — 所有配置自动保存，重启不丢失
- **🎛️ WebUI 配置界面** — 浅色仪表盘风格，24 小时可视化时间轴 + 实时倒计时
- **🔧 管理员权限控制** — 灵活的权限管理，管理员可豁免暂停
- **💬 自定义回复消息** — 暂停期间可自定义回复内容，支持变量替换
- **🌍 多时区支持** — 12+ 常用时区可选

## 📦 安装

1. 将本插件目录放入 `AstrBot/data/plugins/` 下
2. 重启 AstrBot 或在 WebUI 中重载插件
3. 插件会自动安装依赖 `pytz`

## ⚙️ 配置

### WebUI 配置（推荐）

安装后在 AstrBot WebUI 的插件管理页面找到 **定时暂停服务**，点击进入设置页面即可可视化配置。

WebUI 提供以下视图：

- **状态英雄区** — 大图标显示当前运行状态，含实时时间、倒计时、暂停窗口三栏数据
- **24 小时时间轴** — 可视化展示暂停区间（橙色条）和当前时间位置（蓝色游标），跨天场景自动渲染双段
- **本地时钟** — API 刷新间隔内逐秒递增，显示不卡顿
- **一键重置** — 还原为上次保存的配置

### 配置项说明

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enabled` | bool | `true` | 是否启用定时暂停功能 |
| `pause_start` | string | `23:00` | 暂停开始时间（HH:MM） |
| `pause_end` | string | `08:00` | 暂停结束时间（HH:MM），支持跨天 |
| `pause_message` | text | 见下方 | 暂停期间的回复内容 |
| `admin_only` | bool | `true` | 仅管理员可使用指令 |
| `exclude_admin` | bool | `true` | 管理员不受暂停限制 |
| `notify_on_pause` | bool | `false` | 进入/退出暂停时段时通知管理员 |
| `timezone` | string | `Asia/Shanghai` | 时区设置（支持 12+ 常用时区） |

### 默认暂停回复

```
⏰ 当前为休息时间，LLM 服务已暂停。
服务恢复时间：{end_time}
请稍后再试～
```

支持变量：`{start_time}` 暂停开始时间、`{end_time}` 暂停结束时间

## 🎮 指令

| 指令 | 说明 | 权限 |
|------|------|------|
| `/pause_status` | 查看当前暂停状态和配置信息 | 管理员 |
| `/pause_toggle` | 切换定时暂停功能的启用/禁用 | 管理员 |
| `/pause_set <开始> <结束>` | 设置暂停时间段 | 管理员 |


## 🔧 工作原理

1. 插件启动后会创建一个后台异步任务，每 30 秒检查一次当前时间
2. 当检测到当前时间在暂停时段内时，设置暂停标志
3. 通过 `@filter.on_llm_request()` 钩子**仅拦截 LLM 对话调用**：
   - 如果暂停且用户非管理员（或管理员不免除），阻止 LLM 请求并返回自定义提示
   - 指令（如 `/pause_status`）、工具调用、其他插件功能**不受影响**
4. 管理员可以通过指令或 WebUI 随时调整配置

## 📝 注意事项

- 时间比较基于服务器本地时间（可配置时区）
- 暂停检查周期为 30 秒，因此实际暂停/恢复可能有最多 30 秒的延迟
- 跨天设置示例：`23:00 ~ 08:00` 表示 23:00 到次日 08:00
- 非跨天设置示例：`09:00 ~ 18:00` 表示当天 9:00 到 18:00
- WebUI 状态每 15 秒自动刷新，本地时钟逐秒递增
